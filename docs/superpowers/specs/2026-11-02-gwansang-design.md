# 관상 체험 부스 앱 — 설계서

- 작성일: 2026-11-02
- 상태: 초안 (사용자 검토 대기)
- 지식 근거: [wiki/index.md](../../../wiki/index.md) · 프로젝트 규칙: [CLAUDE.md](../../../CLAUDE.md)

## 1. 왜 만드나

부스에서 학생·학부모에게 **"바이브코딩으로 이런 앱도 만들 수 있다"**를 보여 주는 데모다.
체험자는 웹캠 앞에서 30초 남짓 얼굴을 비추고 생년월일을 넣으면, 관상서에 근거한 체험용 풀이를 받고 QR로 휴대폰에 저장해 간다.

## 2. 목표 / 목표 아님 / 실패 기준

**목표**
- 얼굴 측정 → 관상(주) + 사주 + 매화역수(보조)를 오행으로 엮은 **A안 운세 카테고리** 풀이
- 모든 풀이 문장에 "무엇을 봤나 → 근거 → 그래서"가 보임
- 좋은 말 위주, 조심할 점은 근거가 분명할 때만 완곡하게
- 부스 화면 + QR 저장

**목표 아님 (1차 데모)**
- B안 전생 풀이 (위키만 작성됨 → [plan-b-past-life.md](../../../wiki/readings/plan-b-past-life.md))
- 정확한 명리 해석(십신, 대운, 용신), 효사 풀이
- 휴대폰 단독 실행, 다국어

**실패 기준 (돌아가도 실패)**
- 사진·측정값·생년월일·결과가 부스 노트북 밖 서버에 남음
- 체험자를 상처 주는 문장(외모 평가, 질병·수명, 고정관념)이 한 번이라도 나옴
- 결과에 이유가 안 보여 "그냥 랜덤"처럼 느껴짐
- 부스에서 화면이 멈추거나 다음 사람이 앞사람 결과를 보게 됨

## 3. 체험 흐름

참고: 손금 사이트 "수문"의 흐름 + 시선 추적 사이트의 부스 기능.

| # | 화면 | 하는 일 | 다음으로 |
|---|---|---|---|
| 0 | 대기(어트랙트) | 얼굴 윤곽 애니메이션 + "AI가 당신의 관상을 읽어 드려요" | 화면 터치 또는 얼굴 감지 |
| 1 | 생년월일 | 년·월·일 입력, 양력/음력(기본 양력, 음력이면 윤달 체크), 시간(선택, "몰라요" 버튼) | 다음 |
| 2 | 얼굴 맞추기 | 웹캠(좌우 반전) + 가이드 원. "편하게 정면을 봐 주세요". 정면·거리 맞으면 원이 초록 | 자동 |
| 3 | 측정 | 약 3초간 프레임 수집, 얼굴 위에 점·선이 그려지는 연출 | 자동 |
| 4 | 풀이 중 | 측정된 부위를 하나씩 짚는 연출("이마를 보고 있어요…") — Ollama 응답 대기 | 응답 도착 |
| 5 | 결과 | 얼굴 스냅숏 위 부위 표시 + 종합 + 카테고리 6개 + QR | "처음으로" 또는 60초 무입력 |

- 화면 하단 고정: "관상·사주·괘 풀이는 전통 해석을 바탕으로 한 체험용 콘텐츠예요. 사진은 저장되지 않아요."
- 결과 화면을 떠나면 사진 스냅숏, 측정값, 생년월일을 메모리에서 지운다.

## 4. 구조

```
[브라우저 (부스 노트북, 크롬 전체 화면)]
  웹캠 → MediaPipe Face Landmarker (Web Worker) → 측정값 m01–m17
  생년월일 → 만세력 라이브러리 → 사주 오행 / 매화역수 괘
  판정 엔진 (코드) → 오행형, 카테고리 별점, 근거 문구, caution
        │  판정 JSON (사진 없음)
        ▼
[Ollama — 같은 노트북 localhost:11434]  → 풀이 문장 JSON
        │
        ▼
  결과 화면 + QR(결과 요약을 URL # 뒤에 압축)

[휴대폰] QR 스캔 → 정적 결과 페이지(GitHub Pages) → # 뒤 데이터를 읽어 화면에 그림
```

### 결정된 것 (사용자 결정)
- 해석: 로컬 Ollama. 사진과 측정값은 노트북 밖으로 나가지 않음
- 근거: 관상서가 주, 주역은 음양오행 배경 설명
- 통합: 관상 + 사주 + 매화역수를 오행으로 엮음, 관상이 주인공
- 입력: 생년월일 필수, 시간 선택. 양력/음력 선택
- QR: 결과를 URL `#` 뒤에 담아 정적 페이지로. 서버 저장 없음
- 문구: "체험용"
- 태어난 시간을 모르면 체험한 시각의 지지로 괘를 뽑음 → [gigwae.md](../../../wiki/maehwa/gigwae.md)
- 카테고리 7개: 종합, 학업운, 재물운, 애정운(친구·가족의 정 포함), 인간관계운, 건강운, 도전운
- 모델: 부스 노트북은 내장 GPU로 가정 → 작은 모델(3–4B) CPU/내장 GPU 실행. 종합 → 카테고리 순으로 나눠 요청하고 도착한 것부터 화면에 채워 기다림을 연출로 바꿈

### Claude가 정한 것 (검토 부탁)
- **스택**: Vite + TypeScript, 프레임워크 없이. 이유: 화면 6개짜리 단순 앱이고, 부스에서 바이브코딩 시연 때 코드가 읽기 쉬움
- **판정은 코드, 문장은 LLM**: 작은 로컬 모델의 판정 실수를 막기 위해 → [llm-prompt.md](../../../wiki/prompt/llm-prompt.md)
- **모델 후보**: `gemma3:4b`, `qwen2.5:3b`(텍스트 전용). 부스 노트북에서 응답 시간과 한국어 품질을 재고 고름. 둘 다 20초를 넘으면 `gemma3:1b` + fallback 문장 비중 확대
- **별점은 3–5개만**: 낮은 별을 주지 않음
- **QR 압축**: `lz-string`의 `compressToEncodedURIComponent`. 요약(qrSummary 300자 이내) + 카테고리 별점 + 오행형 + 괘 이름만 담음. 얼굴 사진은 담지 않음
- **사주 라이브러리**: `manseryeok-js`(한국천문연구원 기준) 우선, 안 맞으면 `lunar-javascript`

## 5. 부스 운영 기능

- 전체 화면 버튼 + 크롬 키오스크 모드 실행 안내
- 60초 무입력 → 대기 화면으로 자동 리셋(데이터 삭제)
- 운영자 패널(숨김 단축키 `Ctrl+Shift+O`): Ollama 연결 상태, 모델 이름, 평균 응답 시간, 측정 기준선 다시 잡기, 테스트 실행
- Ollama가 죽거나 15초 넘으면 → 미리 쓴 문장 조각(fallback)으로 결과를 만듦. 화면은 멈추지 않음
- 웹캠 오류 메시지는 수문처럼 원인별로 안내(권한 차단, 다른 앱 사용 중, 카메라 없음)

## 6. 데이터 파일 (위키 → 앱)

| 파일 | 내용 | 위키 출처 |
|---|---|---|
| `app/data/landmarks.json` | 측정 항목 id, 랜드마크 번호, 계산식 | measurement-map |
| `app/data/baseline.json` | 측정 항목별 평균·표준편차 | 운영 전 스태프 측정 |
| `app/data/rules.json` | 카테고리별 측정 id, 좋은 모양 근거 문구, caution 조건 | sibigung, samjeong-ogwan, plan-a |
| `app/data/ohaeng.json` | 오행 대응표, 상생·상극 | overview |
| `app/data/hexagrams.json` | 64괘 이름, 한 줄 뜻, 체험용 메시지 | gigwae |
| `app/data/fallback-texts.json` | LLM 실패 시 조립용 문장 조각 | tone-guide |

## 7. 테스트

- **판정 엔진 단위 테스트**: 오행형 판정, 사주 오행 집계(시간 있음/없음), 매화역수 계산(나머지 0 처리 포함), 별점 범위 3–5
- **말투 검사**: LLM 출력에 금지어 목록(수명, 질병, 못생, 뚱뚱 등)이 있으면 fallback으로 바꾸는 필터 + 그 테스트
- **모델 비교**: qwen 계열 vs gemma3, 같은 입력 20건으로 한국어 자연스러움·규칙 위반 수 비교
- **부스 리허설**: 스태프 10명 이상 실제 체험, 1인당 걸리는 시간(목표 90초 이내), 측정 실패율

## 8. 남은 일 / 위험

- 랜드마크 번호는 초안(`confidence: 낮음`). 실제 영상으로 검증 필요
- 마의상법·유장상법·매화역수 원문 발췌 확보 → 위키 g01–g04 검증
- 정적 결과 페이지를 올릴 곳(GitHub Pages 계정/저장소)
- 부스 노트북 사양 확인(GPU 종류, RAM 16GB 이상 권장) → 모델 크기 최종 결정
- "가상 GPU"는 속도를 올려 주지 않음. 실제 GPU가 없으면 CPU로 돌리는 것과 같음
- Ollama를 브라우저에서 부르려면 `OLLAMA_ORIGINS` 환경 변수 설정 필요
