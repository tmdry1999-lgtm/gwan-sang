# B안 — 전생 풀이

> **앱 반영 (2026-11-08)**: 결과 화면 맨 끝에 **"재미로 보세요"** 카드 한 장으로 넣었다. 앱 데이터 `app/data/pastlife.json`.
> 문장은 3줄: 제목 "전생의 당신은 {장면}의 {일}이었어요." → 이유 2문장(얼굴형·괘 / 사주) → "그 기운이 지금 당신에게 {선물}로 남아 있어요."
> 일 이름은 화면에 맞게 줄였다: 선비 · 궁궐 사서 · 약초 의원 / 궁중 악사 · 이야기꾼 · 봉수대 지기 / 마을 촌장 · 객주 주인 · 성 쌓는 장인 / 장군 · 대장장이 명인 · 공정한 판관 / 관상감 천문 관원 · 바다 상인 · 시인. 셋 중 하나는 괘의 동효로 고른다.
> "재미로 보세요"는 사용자가 정한 문구다. "오락용"은 여전히 쓰지 않는다.

> ⚠️ **근거 한계**: 관상서(마의상법 등)에는 전생을 읽는 법이 없다. 조사에서도 전통 근거가 있는 전생 관상 자료를 찾지 못했다.
> 그래서 B안은 **관상·사주·괘의 기질을 "전생 이야기"로 바꿔 들려주는 이야기 장치**다. 화면에도 "기질을 바탕으로 지은 전생 이야기예요"라고 밝힌다.
> 이유 보이기는 그대로 지킨다: "얼굴은 목형 + 괘는 리(불) → 그래서 이런 전생".

## 짓는 방법

1. **얼굴 오행형**(주형) → 전생의 **신분·일 계열**
2. **사주 대표 기운** → 전생의 **성품**
3. **괘(상괘)** → 전생의 **장소·장면**
4. 셋을 엮어 3–4문장 이야기 + "그 기운이 지금의 당신에게 남긴 것"(긍정 1문장)

## 오행형 → 전생 일 계열

| 오행형 | 전생 후보 (긍정 이미지) | 근거 연결 (기질) |
|---|---|---|
| 목형 | 서원의 선비, 궁궐 도서관 사서, 약초를 기르는 의원 | 목 = 성장·배움 |
| 화형 | 궁중 악사, 이야기꾼(전기수), 봉수대 지기 | 화 = 표현·밝음 |
| 토형 | 마을 촌장, 큰 객주 주인, 성을 쌓는 장인 | 토 = 믿음·포용 |
| 금형 | 장군, 대장장이 명인, 공정한 판관 | 금 = 결단·의리 |
| 수형 | 천문을 보는 관상감 관원, 바다를 누빈 상인, 시인 | 수 = 지혜·깊이 |

## 사주 대표 기운 → 성품 · 오행형 → 지금 남은 선물

| 오행 | 전생의 성품 (사주 대표 기운) | 지금 남은 선물 (얼굴 주형) |
|---|---|---|
| 목 | 사람들에게 새로운 것을 가르쳐 주던 | 꾸준히 배우는 힘 |
| 화 | 사람들에게 웃음과 용기를 주던 | 사람을 모으는 말솜씨 |
| 토 | 사람들이 기댈 곳이 되어 주던 | 든든한 믿음 |
| 금 | 한 번 한 약속은 꼭 지키던 | 흔들리지 않는 결단력 |
| 수 | 사람들에게 지혜로운 길을 알려 주던 | 깊은 지혜 |

성품 키워드는 [overview.md](../overview.md)의 오행 대응표를 따른다.

## 괘 → 장면

| 괘 | 장면 |
|---|---|
| 건 | 높은 성루 위 |
| 태 | 연못가 정자 |
| 리 | 등불 밝힌 밤의 장터 |
| 진 | 천둥 치는 첫 출정 길 |
| 손 | 바람 부는 배 위 |
| 감 | 깊은 강가 나루터 |
| 간 | 산속 암자 |
| 곤 | 넓은 들판 마을 |

## 예시

> **전생의 당신은 등불 밝힌 장터의 이야기꾼이었어요.**
> 얼굴은 위가 좁고 아래가 넓은 화형(火形)이라 표현하는 기운이 강하고, 지금 뽑힌 괘의 위쪽이 리(☲, 불)라서 밝은 밤 장면이 떠올라요.
> 사주의 대표 기운인 목(木)은 배우고 자라는 힘이라, 이야기를 들으러 온 사람들에게 새 소식을 전해 주던 사람이었을 거예요.
> ✨ 그 기운이 지금 당신에게 사람을 모으는 말솜씨로 남아 있어요.
