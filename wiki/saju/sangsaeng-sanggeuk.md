# 상생·상극 사주

체험자 사주의 **대표 기운**([ohaeng-balance.md](ohaeng-balance.md))을 기준으로, 어떤 대표 기운을 가진 사람과 잘 맞고(상생) 어떤 사람과 부딪히며 크는지(상극)를 카드 두 장으로 보여 준다. 두 사람을 재지 않는다. 앱 데이터: `app/data/relations.json`

## 고르는 법

| 내 대표 기운 | 상생: 나를 받쳐 주는 | 상생: 내가 힘이 되는 | 상극: 나를 다듬어 주는 | 상극: 내가 중심을 잡아 주는 |
|---|---|---|---|---|
| 목 | 수 (수생목) | 화 (목생화) | 금 (금극목) | 토 (목극토) |
| 화 | 목 (목생화) | 토 (화생토) | 수 (수극화) | 금 (화극금) |
| 토 | 화 (화생토) | 금 (토생금) | 목 (목극토) | 수 (토극수) |
| 금 | 토 (토생금) | 수 (금생수) | 화 (화극금) | 목 (금극목) |
| 수 | 금 (금생수) | 목 (수생목) | 토 (토극수) | 화 (수극화) |

## 이유 문장의 비유

| 관계 | 비유 |
|---|---|
| 목생화 | 나무가 불을 지펴 주듯 |
| 화생토 | 불이 타고 남은 재가 흙을 기름지게 하듯 |
| 토생금 | 흙 속에서 쇠가 자라나듯 |
| 금생수 | 차가운 쇠에 맑은 물방울이 맺히듯 |
| 수생목 | 물이 나무를 키우듯 |
| 목극토 | 나무뿌리가 흙을 단단히 붙잡듯 |
| 토극수 | 흙둑이 물길을 잡아 주듯 |
| 수극화 | 물이 뜨거운 불을 식혀 주듯 |
| 화극금 | 불이 쇠를 녹여 새 모양을 빚듯 |
| 금극목 | 도끼가 나무를 다듬어 쓸모 있게 만들듯 |

## 말투

- 상극도 나쁜 말로 쓰지 않는다 → [overview.md](../overview.md) "세 결과를 엮는 규칙" 2.
  - "누른다·이긴다" 대신 **"다듬어 준다 / 중심을 잡아 준다"**.
  - 첫 문장은 항상 "서로 다른 기운이라 처음엔 부딪힐 수 있지만, 그만큼 배울 게 많은 사이예요."
  - 조언은 해볼 수 있는 행동으로: "생각이 다를 때 먼저 이유를 물어보면 서로에게 더 좋은 짝이 돼요."
- "궁합이 나쁘다", "만나면 안 된다" 같은 말은 쓰지 않는다.

## 예시 (대표 기운 목)

> 🌱 **상생 · 잘 맞는 사주** — 수 · 화
> 내 사주의 대표 기운은 목(木)이에요. 대표 기운이 수(水)인 사람은 물이 나무를 키우듯 나를 받쳐 줘요(수생목). 대표 기운이 화(火)인 사람에게는 나무가 불을 지펴 주듯 내가 힘이 되어 줘요(목생화).
>
> ⚡ **상극 · 부딪히며 크는 사주** — 금 · 토
> 서로 다른 기운이라 처음엔 부딪힐 수 있지만, 그만큼 배울 게 많은 사이예요. 대표 기운이 금(金)인 사람은 도끼가 나무를 다듬어 쓸모 있게 만들듯 나를 더 단단하게 다듬어 줘요(금극목). …
